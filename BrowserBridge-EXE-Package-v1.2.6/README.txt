BrowserBridge EXE packaging folder v1.2.6

1. Install Inno Setup 6 on Windows.
2. Open BrowserBridge-Installer.iss (double-click, or open it in Inno Setup Compiler).
3. Click Compile / press Ctrl+F9.
4. The installer is created at output\BrowserBridge-Windows-Setup-v1.2.6.exe.

All project packaging inputs are included here: the ISS, PowerShell installer, CMD launcher, BrowserBridge runtime archive v2.0.19, and the sun icon. No repository checkout is needed.
